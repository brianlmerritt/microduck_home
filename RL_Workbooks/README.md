# RL workbooks

Read a lesson here, carry out its actions in the project's execution session,
and bring the results back to its `data_parameters.md`. The saved record lets
you stop and return without reconstructing a terminal session.

| Project | Start here |
| --- | --- |
| 01 — Microduck RL tutorial | [Workbook and lesson order](01_microduck_rl_tutorial/README.md) |
| 10 — Experiments | [Experiment plans and results](10_experiments/README.md) |

`02_microduck_rl_human_interactions_lab` is reserved for a later workbook.

The [English RL reference](../docs/rl_reference/README.md) explains environment
definitions and collects translated design notes. The
[interaction plan](../docs/rl_reference/human_interaction_plan.md) connects
checkpoint evaluation, one movement policy and later person/sensor work.

Each lesson has `instructions.md` and `data_parameters.md`. Read the instructions
in Markdown preview; edit the record sheet as Markdown. All result fields start
blank. Examples in the instructions explain what a result looks like; they are
not prefilled claims about your execution session.
